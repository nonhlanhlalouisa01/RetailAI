Executive estimate

Decision view

The existing solution is a five-agent retail intelligence application built on Microsoft Foundry and hosted as a lightweight Azure container. Its cloud infrastructure is modest; AI inference, implementation effort, data integration and social-listening licences are the main cost drivers.

How the estimate works

Transparent assumptions

Per-interaction AI assumption

A normal request is assumed to invoke the Concierge and one specialist: two GPT-4o calls. Across the two calls, the estimate allows 12,000 input tokens, 1,600 output tokens, and one file-search tool call.

Model cost = (12,000 ÷ 1,000,000 × $2.50) + (1,600 ÷ 1,000,000 × $10.00) = $0.0460
File-search call = $2.50 ÷ 1,000 = $0.0025
Estimated variable cost per interaction = $0.0485

Multi-domain requests can call several specialists and cost more. Shorter prompts, cached input or a smaller model can cost less.

What a retailer must have in place

Adoption prerequisites

1. Azure foundation

  • Enterprise Azure subscription and approved landing zone
  • Microsoft Foundry project in an approved region
  • Quota for the selected GPT model and deployment type
  • Container Apps, Container Registry and Log Analytics permissions
  • Entra groups, managed identities and least-privilege RBAC
  • Budget alerts, tags and cost ownership

2. Data readiness

  • Named owners for campaign, product, customer, sentiment and portfolio data
  • Documented source systems, schemas and refresh frequency
  • Data-quality checks and stable customer/SKU/campaign identifiers
  • Approved handling of PII and commercially sensitive data
  • POPIA/GDPR retention, residency and deletion rules
  • Representative UAT dataset and expected-answer test set

3. Integration access

  • Read access or APIs for CRM/CDP, product/PIM, campaign and analytics platforms
  • Approved social provider contracts and webhook permissions if required
  • Corporate DNS, certificates and firewall allow-listing
  • Microsoft Teams admin approval if Teams distribution is required

4. Security and governance

  • AI use policy, acceptable-use controls and human approval points
  • Threat model, penetration test and prompt-injection controls
  • Secrets held in Key Vault; no production API keys in files
  • User authentication and role-based authorization for the application
  • Audit logging without unnecessary prompt or PII retention
  • Model/data risk assessment and responsible-AI review

5. Operations

  • CI/CD with dev, test and production environments
  • Monitoring for availability, latency, errors, tokens and cost
  • Incident response, support rota, SLOs and escalation path
  • Versioned agent prompts, model deployments and rollback
  • Automated knowledge refresh and backup/export process
  • Load, failover and recovery testing

6. People and process

  • Executive sponsor and accountable product owner
  • Retail marketing, analytics and portfolio subject-matter experts
  • Cloud/platform, security, data engineering and AI engineering capacity
  • Legal/privacy/procurement participation
  • User training, adoption metrics and feedback loop
Important gap before enterprise use: the current social-signal store is in memory and business grounding is primarily packaged files. Production use should add durable storage, automated source-system ingestion, application user authentication/authorization, rate limiting and formal monitoring.

Best levers to control cost

  1. Route simple work to a smaller model. Keep GPT-4o for complex analysis while using a mini model for classification, routing and concise summaries.
  2. Limit multi-agent fan-out. Invoke only the necessary specialist and cap retries/tool calls.
  3. Control prompt size. Retrieve fewer, more relevant records; summarize conversation history; exploit cached input where supported.
  4. Set output limits. Default to decision-ready answers and require explicit user action for long reports.
  5. Scale compute to zero. Preserve the current 0–3 replica policy where latency requirements permit.
  6. Track unit economics. Dashboard cost per interaction, per active user, per agent and per business outcome.
